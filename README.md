# Мини-автосалон

Это учебная программа на Python и PySide6. Она показывает список машин, позволяет добавить новую машину и изменить цену выбранной.

При закрытии программа записывает время работы в файл `report.txt`.

## Как запустить

Установить библиотеку:

```text
python -m pip install -r requirements.txt
